# NEXUS — Phone test checklist (Stage 6)

Tick each line and tell me any **No**, with a screenshot if possible.

## After install
- [ ] KLWP loaded NEXUS.klwp without errors
- [ ] Time is correct and big at the top
- [ ] Day name and full date are correct
- [ ] Phone set to 12-hour shows AM/PM. Set to 24-hour shows no AM/PM
- [ ] Weather: 5 days, each with day + date, icon, high, low
- [ ] Rain % shows numbers (not text or blank)
- [ ] Phone button opens Phone
- [ ] Messages button opens Messages
- [ ] All apps button opens the Nova app drawer

## Stocks (after running NEXUS Refresh once)
- [ ] All 5 symbols show a price
- [ ] One price matches Google Finance (within a few cents / a few minutes)
- [ ] Up = green with ▲, down = red with ▼
- [ ] Chart shows 5 colored lines inside the box, all starting from the 0% line
- [ ] Day labels under the chart (e.g. Mon … Fri)
- [ ] "Updated" shows a time

## Over a day or two
- [ ] During market hours the "Updated" time moves every ~5 minutes while you use the phone
- [ ] After the close it says **Market closed** and shows closing prices
- [ ] Airplane mode for 10 minutes during market hours: old prices stay, then red **Offline** or orange **Stale** shows
- [ ] After airplane mode off and a few minutes of use: back to **Live**
- [ ] Restart the phone: everything comes back by itself
- [ ] Settings → Battery: Tasker and KLWP use only a small share (under ~3%)
